Privacy Policy (English)

Effective 2026-09-28

  • Data collected: none. This tool only uploads the owner's own files to the owner's own Google Drive.
  • Google Drive access: uses only the drive.file scope (files created by this app). It cannot see any other file in Drive.
  • Use: uploading backup files and deleting old versions after 30 days.
  • Sharing: none. No advertising, analytics, or sale of data.
  • Sign-in credentials are stored only on the owner's computer and are never sent elsewhere.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
